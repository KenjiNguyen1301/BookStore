# BookStore – Online Bookstore Website

BookStore is a web-based application developed to provide a convenient online book shopping experience. Customers can browse, search, and view book details, manage their shopping carts, place orders using Cash on Delivery (COD), and track their order history. Administrators can manage books, categories, orders, and user accounts.

The project is developed using Java JSP/Servlet, HTML, CSS, JavaScript, and Microsoft SQL Server, with the aim of practicing web application development, database management, and teamwork using GitHub.
